# Большое путешествие

**JavaScript · Model / Presenter / View · Webpack · Day.js · Flatpickr**

Учебный проект HTML Academy

Учебный прототип планировщика поездки: события маршрута, сортировка, избранное и форма редактирования с календарем.

## Подход к разработке

- **Разделение ответственности:** данные, представление и обработка действий пользователя организованы в слоях model / presenter / view.
- **Работа с коллекциями:** сортировку событий по дате, длительности и цене, обновление и удаление записей.
- **Составные формы:** поля направления, типа события, стоимости и дат.
- **Работа с датами:** форматирование и длительность через Day.js, выбор даты и времени через Flatpickr.
- **Сборка frontend-приложения:** Webpack, Babel и выделенные команды разработки.

## Технологии

- HTML, CSS, JavaScript и ES modules;
- разделение model / presenter / view;
- учебный framework HTML Academy;
- Webpack, Babel;
- Day.js;
- Flatpickr;
- ESLint.

## Реализованные возможности

- Отображение четырех событий из локальных мок-данных.
- Сортировка по началу события, длительности и базовой цене.
- Переключение признака избранного.
- Открытие формы существующего события, редактирование полей и удаление события.
- Календарь для выбора даты и времени.

## Структура

```text
src/model/                     # данные маршрута
src/presenter/                 # взаимодействие модели и интерфейса
src/view/                      # элементы и формы
src/mock/                      # события, направления и опции
src/framework/                 # учебный framework
public/                        # шаблон приложения и ресурсы
markup/                        # дополнительные HTML-макеты
```

## Локальный запуск

В `package.json` указана версия Node.js 20. Для установки зависимостей нужен npm.

Скачайте исходники [`master`](https://github.com/Takiera/1040325-big-trip-23/tree/master), распакуйте их и откройте терминал в корне проекта.

```bash
npm ci
npm run start
```

Webpack Dev Server запускает приложение и открывает браузер.

Production-сборка:

```bash
npm run build
```

Проверка JavaScript линтером:

```bash
npm run lint
```
